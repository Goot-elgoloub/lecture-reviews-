شريحة 04 — Components of a Recurrence Relation

المصدر — SOURCE

Every recurrence has three parts that together fully describe the algorithm's cost.

  1. 1. Recursive Part — The cost of solving smaller subproblems. T(n/2) or 2T(n/2)
  2. 2. Outside Work — Operations performed at the current level — dividing and combining. + c or + n
  3. 3. Base Case — The stopping condition — the smallest input size. T(1) = c

Binary Search: T(n) = T(n/2) + c, with base case T(1) = c. The equation mirrors the algorithm's structure.

الشريحة تحتوي أيقونات صغيرة زخرفية (ثلاث دوائر) بلا نص.

الصيغة: T(n)=T(n/2)+c , T(1)=c

قراءة قارئ الشاشة: تي إن تساوي تي نصف إن زائد سي، وتي واحد تساوي سي.

شريحة 05 — Solving a Simple Recurrence

المصدر — SOURCE

RECURRENCE RELATIONS

Consider T(n) = T(n/2) + c. Each expansion adds one more level of work:

  • Level 1 — T(n) = T(n/2) + c
  • Level 2 — T(n) = T(n/4) + 2c
  • Level 3 — T(n) = T(n/8) + 3c
  • After k levels — T(n) = T(n/2ᵏ) + kc

Recursion stops when n/2ᵏ = 1, so k = log₂ n. Result: T(n) = Θ(log n). Repeated division by 2 produces logarithmic depth.

الشريحة تحتوي صورة زخرفية (شجرة بلا نص).

الصيغة: T(n)=T(n/2^k)+k*c

قراءة قارئ الشاشة: تي إن تساوي تي نصف إن أس كاي زائد كاي في سي.

الصيغة: n/2^k=1 => k=log2(n) => T(n)=Theta(log n)

قراءة قارئ الشاشة: إن على اثنين أس كاي تساوي واحد، إذن كاي تساوي لوغاريتم إن للأساس اثنين، إذن تي إن ثيتا لوغاريتم إن.

تحليل التعقيد (4 خطوات)

شرح — EXPLANATION
  1. Identify: العملية السائدة هي الإضافة c عند كل مستوى.
  2. Count: عدد المستويات k = log₂ n.
  3. Express T(n): T(n) = T(1) + c·log₂ n.
  4. Simplify: نُسقط الثابتين فيبقى Θ(log n).
شرح إضافي — ADDITIONAL

مثال عددي إضافي: n = 1024 فيكون k = 10 مستويات (2¹⁰ = 1024)، أي نحو 10 مرات العمل c، بينما البحث الخطي يحتاج 1024 خطوة.

شرح جملة بجملة

شرح — EXPLANATION

For any polynomial or asymptotic expression, focus on the term that grows fastest as n → ∞. Lower-order terms and constants fade into insignificance.

  2. T(n) = 8n + 20 — Dominant: n → Θ(n)
  3. T(n) = 4n³ + 2n² + n + 1 — Dominant: n³ → Θ(n³)
  4. T(n) = n log₂ n + 10n — Dominant: n log n → Θ(n log n)

شريحة 08 — Big O vs. Big Theta

المصدر — SOURCE

ASYMPTOTIC NOTATION

Big O — Upper Bound

f(n) = O(g(n))

f(n) grows no faster than g(n). It's a ceiling — the algorithm won't take longer than this.

Big Theta — Tight Bound

f(n) = Θ(g(n))

f(n) and g(n) share the same asymptotic growth rate. It's a precise characterization.

Exam Tip: n = O(n²) is true, but n = Θ(n²) is false. The tightest description is n = Θ(n). A Big O bound can be correct without being the tightest.

الصيغة: f(n)=O(g(n))

قراءة قارئ الشاشة: إف إن تساوي أو كبيرة من جي إن (حد أعلى).

الصيغة: f(n)=Theta(g(n))

قراءة قارئ الشاشة: إف إن تساوي ثيتا من جي إن (حد محكم).

الشريحة تحتوي أيقونة صغيرة زخرفية بلا نص.

شرح جملة بجملة

شرح — EXPLANATION

  1. “f(n) = O(g(n)): f(n) grows no faster than g(n). It's a ceiling”

    Big O حد أعلى: f لا ينمو أسرع من g، وهو سقف لا تتجاوزه الخوارزمية.

  2. “f(n) = Θ(g(n)): f(n) and g(n) share the same asymptotic growth rate.”

    Big Theta حد محكم: f وg لهما معدل النمو نفسه، وهو توصيف دقيق.

  3. “n = O(n²) is true, but n = Θ(n²) is false.”

    n = O(n²) صحيحة لأن n² سقف لـ n، لكن n = Θ(n²) خاطئة لأن n لا ينمو بنفس معدل n².

  4. “A Big O bound can be correct without being the tightest.”

    حد Big O قد يكون صحيحًا دون أن يكون الأحكم.

شرح موسّع

شرح — EXPLANATION
تشبيه: "عمري أقل من 100 سنة" صحيحة لكنها غير محكمة، بينما "عمري 25" محكمة. وهكذا O للسقف وΘ للقيمة الدقيقة. (تشبيه منا.)
تحدٍّ سريع: هل n = Θ(n²) صحيحة؟

لا.

خلاصة — TAKEAWAY

O سقف وΘ حد محكم؛ O قد يكون صحيحًا وغير محكم.

Algorithm → Recurrence → Solve → Classify

المستويات">

البحث الثنائي مثل البحث عن كلمة في قاموس: تفتح المنتصف وتتخلص من نصف الصفحات. كم مرة تنصّف 1000 صفحة حتى تصل إلى صفحة واحدة؟ حوالي 10 مرات؛ هذا هو log n. وعلاقة التكرار تكتب ما يحدث: عمل بسيط ثم نصف المسألة.

علاقة التكرار T(n)=aT(n/b)+f(n) تتكون من جزء تكراري وعمل خارجي وحالة أساسية. تُحلّ بالتوسيع أو شجرة العودية أو التعويض (خمّن وعوّض وأثبت بالاستقراء). Master Theorem يقارن f(n) مع n^(log_b a): أصغر فالناتج Θ(n^(log_b a))، متساوٍ فالناتج Θ(n^(log_b a) log n)، أكبر مع regularity فالناتج Θ(f(n)). لا تنطبق على T(n−1)+n ولا على المسائل غير المتساوية.

  • Parts: recursive part, outside work, base case.
  • T(n)=T(n/2)+c = Θ(log n); T(n)=T(n−1)+1 = Θ(n); T(n)=2T(n/2)+n = Θ(n log n).
  • Big O = ceiling; Θ = tight. n = O(n²) true, n = Θ(n²) false.
  • log n < n < n log n < n² < n³ < 2ⁿ.
  • Master: compare f(n) with n^(log_b a); strategy Calculate → Compare → Classify → Solve.
  • Not applicable: constant reduction, unequal subproblems, non D&C.
