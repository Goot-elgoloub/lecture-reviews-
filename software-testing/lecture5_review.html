01 نظرة عامة

عن ماذا تتحدث المحاضرة

تغطي هذه المحاضرة تقنيات تصميم حالات اختبار الصندوق الأسود، وتحديداً تحليل القيم الحدية (BVA) وعلاقته بتقسيم التكافؤ. تشرح كيفية تحديد حدود أقسام التكافؤ المرتبة وإنشاء حالات اختبار تستهدف الحواف حيث تكون العيوب أكثر احتمالاً للاختباء.

المشكلة الرئيسية التي تعالجها هي أن العيوب تميل إلى التجمع عند حدود أقسام المدخلات، وليس في المنتصف. توفر المحاضرة طريقة منهجية لاكتشاف عيوب الحدود هذه باستخدام تحليل الحدود ذي النقطتين وثلاث نقاط.

الفكرة الأساسية

السلوك عند حدود أقسام التكافؤ أكثر عرضة للخطأ من السلوك داخل الأقسام. يُجبر تحليل القيم الحدية البرنامج على إظهار سلوكيات من قسم مختلف عن القسم الذي يجب أن تنتمي إليه القيمة الحدية، مما يكشف العيوب عند الحواف.

قائمة المفاهيم الرئيسية

  • تعريف وتحليل القيم الحدية (BVA) والغرض منه
  • مراجعة تقسيم التكافؤ (الأقسام المرتبة)
  • تحليل الحدود ذو النقطتين مقابل ثلاث نقاط
  • تحديد القيم الحدية للأقسام الصحيحة وغير الصحيحة
  • مشاكل تداخل الحدود الشائعة (مثل قواعد العمر)
  • خطوات تطبيق اختبار القيم الحدية
  • اختيار النقاط الأدنى/الأعلى نسبةً لوحدات البيانات

المهارات المكتسبة

  • تحديد أقسام التكافؤ وحدودها
  • تطبيق تحليل القيم الحدية على المدخلات الرقمية والتسلسلية
  • إنشاء حالات اختبار للقيم الحدية باستخدام طريقتي النقطتين وثلاث نقاط
  • التعرف على عيوب تداخل الحدود وإصلاحها في الأنظمة القائمة على القواعد
  • شرح لماذا تعتبر الحدود مناطق عالية المخاطر للعيوب

لماذا هذا مهم

يعرف المختبِرون ذوو الخبرة أن العيوب تتجمع عند الحدود. من خلال تركيز جهود الاختبار على حواف نطاقات الإدخال، يمكنك العثور على المزيد من العيوب باستخدام حالات اختبار أقل. هذه التقنية ضرورية لأي نظام يحتوي على نطاقات إدخال رقمية أو تسلسلية — من التحقق من العمر إلى عتبات الرواتب إلى نطاقات التواريخ.

Boundary Value Analysis

Boundary value analysis (BVA) is an extension of equivalence partitioning, but can only be used when the partition is ordered, consisting of numeric or sequential data.

For example, suppose an input field accepts a single integer value as an input, using a keypad to limit inputs so that non-integer inputs are impossible. The valid range is from 1 to 5, inclusive. So, there are three equivalence partitions:

Reading order:

  2. Row 2: "valid" → arrow → "1 to 5"
  3. Row 3: "invalid (too high)" → arrow → "More than 5"

Meaning: The input range 1–5 is divided into three equivalence partitions. The valid partition is 1 to 5. The invalid partitions are below 1 and above 5.

For the valid equivalence partition, the boundary values are 1 and 5. For the invalid (too high) partition, the boundary value is 6. For the invalid (too low) partition, there is only one boundary value, 0, because this is a partition with only one member.

Sentence 1: "Boundary value analysis (BVA) is an extension of equivalence partitioning, but can only be used when the partition is ordered, consisting of numeric or sequential data."

يبني تحليل القيم الحدية على تقسيم التكافؤ. يتطلب بيانات مرتبة (أرقام، تسلسلات) حتى يمكن تحديد الحدود بين الأقسام.

Sentence 2: "For example, suppose an input field accepts a single integer value... The valid range is from 1 to 5, inclusive."

يحدد المثال حقل إدخال يقبل فقط الأعداد الصحيحة من 1 إلى 5. هذا يخلق ثلاثة أقسام: أقل من 1 (غير صحيح)، 1–5 (صحيح)، وأكثر من 5 (غير صحيح).

Sentence 3: "For the valid equivalence partition, the boundary values are 1 and 5. For the invalid (too high) partition, the boundary value is 6. For the invalid (too low) partition, there is only one boundary value, 0, because this is a partition with only one member."

حدود القسم الصحيح [1، 5] هي 1 و5. أول قيمة غير صحيحة فوق القسم الصحيح هي 6. أول قيمة غير صحيحة تحت هي 0. هذه هي القيم التي نختبرها.

EXPLANATION — Expanded

الرؤية الأساسية هي أننا لا نختبر جميع القيم في النطاق 1–5. بدلاً من ذلك، نختبر القيم الحدية (1 و5) والقيم خارج الحدود مباشرة (0 و6). تغطي حالات الاختبار الأربع هذه المناطق الأكثر عرضة للعيوب.

الخلاصة: بالنسبة للنطاق الصحيح 1–5، القيم الحدية هي 1 و5. بالنسبة للأقسام غير الصحيحة، القيم الحدية هي 0 (أدنى) و6 (أعلى).

Slide 04 — الحدود ذات النقطتين وثلاث نقاط

SOURCE — Original Content

In the example above, we identify two boundary values per boundary. The boundary between invalid (too low) and valid gives the test values 0 and 1. The boundary between valid and invalid (too high) gives the test values 5 and 6. Some variations of this technique identify three boundary values per boundary: the values before, at, and just over the boundary. In the previous example, using three-point boundary values, the lower boundary test values are 0, 1, and 2, and the upper boundary test values are 4, 5, and 6.

Behavior at the boundaries of equivalence partitions is more likely to be incorrect than behavior within the partitions. Boundary value analysis and testing will reveal almost all such defects by forcing the software to show behaviors from a partition other than the one to which the boundary value should belong.

EXPLANATION — Sentence-by-Sentence

Sentence 1: "In the example above, we identify two boundary values per boundary."

تختبر طريقة النقطتين قيمتين عند كل حد: القيمة الحدية نفسها والقيمة خارج القسم مباشرة.

Sentence 2: "The boundary between invalid (too low) and valid gives the test values 0 and 1. The boundary between valid and invalid (too high) gives the test values 5 and 6."

عند الحد الأدنى: 0 (غير صحيح) و1 (صحيح). عند الحد الأعلى: 5 (صحيح) و6 (غير صحيح).

Sentence 3: "Some variations of this technique identify three boundary values per boundary: the values before, at, and just over the boundary."

تضيف طريقة الثلاث نقاط قيمة إضافية على الجانب الآخر من الحد — اختبار القيمة داخل القسم بالقرب من الحد.

Sentence 4: "In the previous example, using three-point boundary values, the lower boundary test values are 0, 1, and 2, and the upper boundary test values are 4, 5, and 6."

ثلاث نقاط السفلى: 0 (أدنى)، 1 (عند الحد)، 2 (أعلى). ثلاث نقاط العليا: 4 (أدنى)، 5 (عند الحد)، 6 (أعلى).

Sentence 5: "Behavior at the boundaries of equivalence partitions is more likely to be incorrect than behavior within the partitions."

تتجمع العيوب عند الحدود. عادةً ما يتم اختبار منتصف القسم جيداً بالاستخدام العادي؛ الحواف هي حيث يمكن أن يخطئ منطق الكود (مثل < مقابل <=).

Sentence 6: "Boundary value analysis and testing will reveal almost all such defects by forcing the software to show behaviors from a partition other than the one to which the boundary value should belong."

من خلال اختبار 0 (الذي يجب أن يكون غير صحيح) و1 (الذي يجب أن يكون صحيحاً)، نجبر البرنامج على إظهار القسم الذي يعتقد أن كل قيمة تنتمي إليه. إذا تعامل مع 1 على أنه غير صحيح، نجد العيب.

EXPLANATION — Expanded

طريقتا النقطتين والثلاث نقاط كلاهما صالحتان. طريقة النقطتين أكثر شيوعاً وكافية لمعظم الحالات. توفر طريقة الثلاث نقاط تغطية إضافية من خلال اختبار قيمة واحدة داخل القسم الصحيح بالقرب من الحد، والتي يمكن أن تكشف العيوب حيث يتم إزاحة الحد بوحدة واحدة.

الخلاصة: يستخدم اختبار النقطتين {0، 1} و{5، 6}. يضيف اختبار الثلاث نقاط قيمة واحدة داخل القسم الصحيح: {0، 1، 2} و{4، 5، 6}. الحدود هي مناطق عالية المخاطر للعيوب.

Slide 05 — مشكلة تداخل الحدود (قواعد العمر)

SOURCE — Original Content

In the previous example of Equivalence Partition the following rules were given that indicate how we should process employment applications based on a person's age. The rules were:

  • 0 - 16 Don't hire
  • 16 - 18 Can hire on a part-time basis only
  • 18 - 55 Can hire as a full-time employee
  • 55 - 99 Don't hire

Notice the problem at the boundaries—the "edges" of each class. The age "16" is included in two different equivalence classes (as are 18 and 55). The first rule says don't hire a 16-year old. The second rule says a 16-year-old can be hired on a part-time basis.

EXPLANATION — Sentence-by-Sentence

Sentence 1: "In the previous example of Equivalence Partition the following rules were given..."

قواعد العمر هذه من مثال محاضرة سابق حول طلبات التوظيف.

Sentence 2: "Notice the problem at the boundaries—the 'edges' of each class. The age '16' is included in two different equivalence classes (as are 18 and 55)."

تتداخل القواعد عند 16 و18 و55. على سبيل المثال، 16 موجود في كل من '0-16' و'16-18'. هذا يخلق غموضاً: أي قاعدة تنطبق على شخص عمره 16؟

Sentence 3: "The first rule says don't hire a 16-year old. The second rule says a 16-year-old can be hired on a part-time basis."

هذا تناقض. نفس العمر (16) له نتيجتان مختلفتان اعتماداً على القاعدة المطبقة. هذا عيب في القواعد نفسها.

EXPLANATION — Expanded

تداخل الحدود هو عيب شائع في الأنظمة القائمة على القواعد. عندما تتضمن قاعدتان نفس القيمة الحدية (على سبيل المثال، 16 موجود في كل من '0-16' و'16-18')، يصبح سلوك النظام غامضاً. الإصلاح هو جعل القواعد غير متداخلة باستخدام متباينات صارمة على جانب واحد.

الخلاصة: يسبب تداخل الحدود الغموض. يظهر العمر 16 في قاعدتين بنتائج متناقضة. هذا عيب في القاعدة، وليس عيباً في البرمجة.

Slide 08 — خطوات اختبار القيم الحدية

SOURCE — Original Content

The steps for using boundary value testing are simple:

  1. First, identify the equivalence classes.
  2. Second, identify the boundaries of each equivalence class.
  3. Third, create test cases for each boundary value by choosing one point on the boundary, one point just below the boundary, and one point just above the boundary.

"Below" and "above" are relative terms and depend on the data values units.

If the boundary is 16 and the unit is "integer" then the "below" point is 15 and the "above" point is 17.

If the boundary is $5.00 and the unit is "US dollars and cents":

  • The below point is $4.99
  • The above point is $5.01
EXPLANATION — Sentence-by-Sentence

Step 1: "Identify the equivalence classes."

قسّم مجال الإدخال إلى أقسام حيث يجب أن تعامل جميع القيم في القسم بنفس الطريقة بواسطة البرنامج.

Step 2: "Identify the boundaries of each equivalence class."

لكل قسم، ابحث عن القيم الدنيا والعليا. هذه هي الحدود.

Step 3: "Create test cases for each boundary value by choosing one point on the boundary, one point just below the boundary, and one point just above the boundary."

لكل حد، اختبر ثلاث قيم: الحد نفسه، وحدة أدنى، ووحدة أعلى.

Sentence 4: "'Below' and 'above' are relative terms and depend on the data values units."

يتغير معنى 'أدنى' و'أعلى' مع نوع البيانات. بالنسبة للأعداد الصحيحة، هو ±1. بالنسبة للعملة، هو ±0.01.

Sentence 5: "If the boundary is 16 and the unit is 'integer' then the 'below' point is 15 and the 'above' point is 17."

مثال صحيح: الحد = 16، الأدنى = 15، الأعلى = 17.

Sentence 6: "If the boundary is $5.00 and the unit is 'US dollars and cents': The below point is $4.99. The above point is $5.01."

مثال العملة: الحد = 5.00$، الأدنى = 4.99$، الأعلى = 5.01$. الوحدة هي السنت، لذا نتحرك بمقدار 0.01.

EXPLANATION — Expanded

تشكل الخطوات الثلاث إجراءً منهجياً: قسّم فضاء الإدخال، ابحث عن حواف كل قسم، واختبر القيم عند، وأدنى، وأعلى كل حافة. الدقة الأساسية هي أن 'أدنى' و'أعلى' يعتمدان على وحدة القياس. للأعداد الصحيحة، هو ±1؛ للأرقام العشرية، هو ±0.01؛ للتواريخ، هو ±1 يوم؛ إلخ.

الخلاصة: الخطوات: 1) حدد أقسام التكافؤ. 2) حدد الحدود. 3) اختبر عند، وأدنى، وأعلى كل حد. يعتمد 'أدنى' و'أعلى' على وحدة البيانات (صحيح ±1، عملة ±0.01).

شرح أكاديمي

تحليل القيم الحدية (BVA) هو تقنية تصميم اختبار الصندوق الأسود التي تمتد على تقسيم التكافؤ. وهي قابلة للتطبيق فقط على أقسام التكافؤ المرتبة — الأقسام التي تتكون من بيانات رقمية أو تسلسلية.

بالنسبة لقسم [أ، ب]، القيم الحدية هي أ و ب. بالنسبة للقسم غير الصحيح تحت أ، القيمة الحدية هي أ-1. بالنسبة للقسم غير الصحيح فوق ب، القيمة الحدية هي ب+1.

تختبر طريقة النقطتين {أ-1، أ} و{ب، ب+1}. تختبر طريقة الثلاث نقاط {أ-1، أ، أ+1} و{ب-1، ب، ب+1}.

التعريف الرسمي لقسم التكافؤ: قسم من مجال الإدخال D هو مجموعة من المجموعات الفرعية D₁، D₂، ...، Dₙ بحيث يكون D₁ ∪ D₂ ∪ ... ∪ Dₙ = D و Dᵢ ∩ Dⱼ = ∅ لـ i ≠ j.

من حيث الكود: إذا كان (x >= a && x <= b) صحيحاً، فإن الحدود هي a و b. قيم الاختبار هي a-1، a، b، b+1.

ملاحظات المراجعة السريعة

  • تحليل القيم الحدية = تقنية صندوق أسود للأقسام المرتبة.
  • نقطتان: اختبار الحد ± 1 وحدة.
  • ثلاث نقاط: اختبار الحد، والأدنى، والأعلى.
  • تتجمع العيوب عند الحدود — لهذا يعمل تحليل القيم الحدية.
  • تداخل الحدود يسبب الغموض (مثل العمر 16 في قاعدتين).
  • الإصلاح: اجعل النطاقات غير متداخلة (0-15، 16-17، 18-54، 55-99).
  • الخطوات: 1) حدد الأقسام. 2) حدد الحدود. 3) اختبر عند، وأدنى، وأعلى.
  • تحليل القيم الحدية الأفضل للنطاقات المستمرة (الدخل، العمر، درجة الحرارة).
