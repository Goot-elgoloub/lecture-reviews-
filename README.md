# 📚 مراجعات المحاضرات | Lecture Reviews

ملفات مراجعة (HTML) للمحاضرات، مرتبة حسب المادة والمحاضرة.

🔗 الموقع: https://goot-elgoloub.github.io/lecture-reviews-/

المشروع بيحتوي على ملفات مراجعة سريعة لمحاضرات المواد التالية:

- 🌐 هندسة تطبيقات الويب — `web-engineering`
- 🔒 أمن المعلومات — `information-security`
- 🧮 تحليل وتصميم الخوارزميات — `algorithms`
- 🧪 اختبار جودة البرمجيات — `software-testing`
- 📊 تنقيب البيانات — `data-mining`
- 💡 ريادة الأعمال والإبداع في تقانة المعلومات — `entrepreneurship`

كل مادة ليها مجلد خاص بيها، وجوه كل مجلد ملفات الـ HTML الخاصة بمحاضرات المادة. افتحي رابط الموقع فوق، اختاري المادة، وبعدين اختاري المحاضرة اللي عايزة تراجعيها.

⚠️ الملفات دي مراجعات مساعدة لتسهيل المذاكرة، وممكن تحتوي على أخطاء بسيطة، فهي مش بديل عن المحاضرة أو المصدر الرسمي للمادة. لو لاقيتي أي خطأ أو عندك اقتراح لمحاضرة ناقصة، افتحي Issue جديد في الريبو.

المشروع بيتحدث بشكل مستمر بمحاضرات جديدة أول بأول مع تقدم السمستر.
